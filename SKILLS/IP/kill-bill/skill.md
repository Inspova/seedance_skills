# Kill Bill

## Purpose

This skill governs the application of the visual style of *Kill Bill* for Seedance.

Kill Bill's style is not simply sword fights, blood, or yellow costumes. It is a complete cinematic language built around graphic visual storytelling, heightened action, bold color design, stylized violence, and genre fusion.

When activated, this skill should transform the visual language into an energetic, highly stylized action film inspired by martial arts cinema, spaghetti westerns, samurai epics, exploitation films, and graphic novels.

Its most recognizable visual signature is a strong cinematic yellow palette, contrasted with deep blacks, saturated reds, and clean graphic compositions.

The goal is not realism.

The goal is stylish cinematic spectacle.

- graphic violence

- action choreography
- camera
- composition
- lighting
- color
- costumes
- pacing
- atmosphere

Every artistic decision should reinforce:

- cinematic confidence
- graphic simplicity
- explosive action

---

# Visual Translation

Never rely solely on:

```
Kill Bill style
```

Instead describe:

- bold yellow cinematic color palette
- graphic black contrast
- stylized martial arts action
- samurai-inspired framing
- dramatic close-ups
- energetic camera movement
- comic-book visual language
- high-contrast lighting
- dynamic compositions

The resulting prompt should still feel unmistakably Kill Bill even if the title is removed.

---

# Style Boundaries

Avoid reducing the style to:

- yellow tracksuits
- katanas
- blood alone
- martial arts clichés

The defining qualities are graphic storytelling, cinematic confidence, and bold visual design.

---

# Integration

When multiple skills are active, Kill Bill should dominate:

- action presentation
- visual rhythm
- color palette
- camera energy
- graphic compositions

Preserve the original story while transforming the cinematic presentation.

---

# Narrative Preservation

Do not rewrite the narrative.

Preserve:

- characters
- setting
- story
- actions

Only transform the filmmaking style.

---

# Default Behavior

If Kill Bill is not requested, do not activate this skill.

Kill Bill is a complete cinematic language where bold color, dynamic action, graphic compositions, and genre stylization transform ordinary action into iconic cinematic spectacle.
