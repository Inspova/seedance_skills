# Image Finishing

## Purpose

This skill governs image finishing techniques for Seedance.

Image finishing represents the final stage of post-processing that refines the overall appearance of an image without fundamentally altering its content. These treatments enhance texture, atmosphere, perceived optics, and visual cohesion after the primary cinematography and color decisions have been established.

Its purpose is to apply finishing effects that strengthen mood, realism, or artistic intent while preserving the integrity of the original image.

# When to Use

Apply this skill when the user explicitly requests finishing treatments or when subtle image refinement naturally supports the creative goal.

Typical indicators include:

- film grain
- analog texture
- vintage film
- aged imagery
- bloom
- glow
- soft diffusion
- dreamy atmosphere
- romantic visuals
- nostalgic appearance
- cinematic polish
- optical softness

Do not activate this skill simply because the user requests cinematic imagery.

Only apply finishing treatments when they meaningfully support the intended visual language.

---

# Application Philosophy

Treat image finishing as the final polish of the image.

Its influence should naturally reinforce:

- atmosphere
- emotional tone
- perceived realism
- optical character
- visual cohesion
- cinematic texture

Finishing effects should complement existing cinematography rather than compete with it.

Subtle, well-integrated finishing is almost always preferable to aggressive processing.

Avoid stacking multiple strong finishing effects unless a highly stylized aesthetic is explicitly requested.

---

# Visual Translation

Rather than outputting only:

```
Film Grain
```

or

```
Bloom Effect
```

translate the chosen treatment into concrete visual decisions.

Describe elements such as:

- organic film texture
- subtle analog imperfections
- soft highlight bloom
- gentle optical diffusion
- nostalgic image character
- restrained visual softness
- cohesive cinematic finish

The treatment should be expressed through visible image qualities rather than effect names alone.

---

# Style Boundaries

Avoid treating finishing effects as decorative overlays.

Every effect should reinforce the established visual language created by:

- cinematography
- lighting
- color processing
- cinematic movement
- director style

Avoid excessive processing that distracts from the subject or makes the image appear artificial.

When multiple finishing treatments are appropriate, prioritize visual harmony over quantity.

---

# Default Behavior

If no finishing effects are requested and none naturally support the scene:

- preserve clean image quality
- avoid unnecessary stylization
- maintain natural texture
- apply minimal finishing

The image should appear professionally finished without drawing attention to the post-processing itself.

---

# Final Principle

Image finishing should enhance what already exists.

It is the final refinement that strengthens atmosphere, texture, and cinematic cohesion—not a substitute for strong cinematography, lighting, or composition.

The best finishing effects are often the ones the audience notices the least while still feeling their emotional impact.
