# Personality

## Purpose

Choose personality traits that remain relatively stable throughout the story.

Personality influences how characters interpret events, solve problems, communicate, and respond emotionally.

Unlike emotions, personality should change only through meaningful character development.

---

# Analytical

## Sample Prompt

Portray a character with an analytical personality through careful observation, logical decision-making, and structured behavior. Show them processing information before acting, noticing details others miss, and approaching problems methodically.

## Characteristics

- logical
- observant
- rational
- thoughtful
- methodical

## Best For

- detectives
- scientists
- strategists
- scholars

# Personality Rules

## Sample Prompt

Build personalities by combining multiple compatible traits that create believable strengths, weaknesses, and contradictions. Avoid reducing characters to a single defining adjective.

Examples:

Analytical + Compassionate

Reserved + Ambitious

Confident + Idealistic

Outgoing + Impulsive

Avoid combining strongly contradictory traits unless the contradiction is intentional and supported by the story.

---

# Default

## Sample Prompt

If personality is unspecified, create a balanced and emotionally believable personality with both strengths and flaws. Avoid overly perfect characters; include realistic habits, limitations, and individual differences.

If personality is unspecified:

- prefer balanced personalities
- include both strengths and weaknesses
- maintain consistency throughout the story
