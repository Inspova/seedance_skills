# Character

## Purpose

This module governs all character-related decisions for Seedance.

Its goal is to create characters that are visually believable, emotionally readable, and consistent throughout a scene.

Character design should support:

- storytelling
- personality
- emotional expression
- visual identity
- world-building

A character should never feel like a collection of disconnected visual features.

Every appearance decision should communicate something about:

- who the character is
- what they have experienced
- how they feel
- how they exist in their environment

---

# Character Intent

Treat character creation as a professional character designer and cinematographer would.

A strong character is not created through maximum detail.

A strong character is created through:

- intentional features
- consistent design language
- believable anatomy
- meaningful imperfections
- emotional connection

When multiple valid choices exist, prefer the choice that improves:

1. character identity
2. story relevance
3. realism
4. visual coherence

# Character Construction Process

Before generating a character, determine:

## 1. Character Role

Identify:

- protagonist
- antagonist
- supporting character
- background character

The role determines the level of visual specificity.

---

## 2. Character Identity

Define:

- age range
- gender presentation
- cultural context
- occupation
- personality
- background

Appearance should reflect identity.

Example:

A warrior should not only wear armor.

Their:

- posture
- scars
- expression
- clothing condition

should communicate their history.

---

## 3. Visual Design Layer

Build the character in this order:

1. silhouette
2. body structure
3. clothing
4. head and facial identity
5. details and imperfections

Large-scale decisions should be established before small details.

---

# Character Realism Contract

Characters must obey:

- believable human anatomy
- realistic material interaction
- consistent age appearance
- natural facial structure
- physically plausible clothing
- coherent body proportions

Avoid:

- impossible anatomy
- inconsistent age cues
- random accessories
- artificial perfection
- disconnected visual elements

---

# Human Imperfection Rules

Realistic characters require controlled imperfections.

Prefer:

- uneven skin tone
- natural pores
- fine facial hair
- wrinkles
- scars
- freckles
- clothing wrinkles
- small asymmetries

Avoid:

- flawless skin
- identical facial symmetry
- perfect hair placement
- unrealistic body proportions

Imperfections should enhance identity, not distract from it.

---

# Character Consistency

Throughout a shot or sequence, maintain:

## Face

- facial structure
- hairstyle
- makeup
- distinctive marks

## Body

- proportions
- physical condition
- posture
- movement style

## Clothing

- colors
- materials
- damage
- accessories

Avoid changing character identity without narrative reason.

---

## Body

## Clothing

# Detail Priority

When detail conflicts with clarity, prioritize:

1. recognizable character identity
2. emotional readability
3. silhouette
4. realism
5. secondary details

Do not overload characters with unnecessary details.

# Character Lighting Relationship

Characters should interact naturally with lighting.

Consider:

- skin response
- material reflection
- hair highlights
- clothing texture

Reference:

`lighting/`

---

# Character Output Rules

When describing characters, specify where relevant:

- identity
- age
- appearance
- body
- clothing
- emotional state
- distinctive features
- movement behavior

Avoid generic descriptions such as:

"beautiful person"

Prefer:

"a young musician with tired eyes, slightly messy hair, worn clothing, and a relaxed posture showing years of late-night practice."

---

# Conflict Resolution

If character instructions conflict:

Prioritize:

1. character identity
2. emotional purpose
3. realism
4. visual style
5. decorative details

Ignore lower-priority details if they damage character consistency.

---

# Default Behaviour

If no character details are provided:

Create a believable character using:

- natural anatomy
- realistic skin
- coherent clothing
- subtle imperfections
- emotionally neutral expression

Avoid:

- exaggerated beauty
- fantasy-like perfection
- unnecessary accessories

The default character should feel like a real person, not a generated model.

---

# Output

Character descriptions should define:

- who the character is
- how they look
- how they feel
- how they move
- how they exist in the world

Every character choice should serve the story.
