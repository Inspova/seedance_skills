# Color Processing

## Purpose

This skill governs color processing for Seedance.

Color processing establishes the tonal and chromatic foundation of an image through technical color management and tonal refinement. Unlike image finishing, which adds stylistic polish, or optical effects, which simulate photographic lens behavior, color processing controls the overall balance, consistency, and dynamic range of the captured image.

Its purpose is to create a coherent color foundation that supports realism, emotional storytelling, and cinematic continuity before any additional stylistic treatments are applied.

# When to Use

Apply this skill when the user explicitly requests color refinement or when proper tonal and color management naturally supports the creative goal.

Typical indicators include:

- color correction
- white balance
- warm or cool color temperature
- accurate skin tones
- dynamic range
- HDR
- highlight recovery
- shadow detail
- tonal consistency
- cinematic grading foundation
- realistic color reproduction

Do not activate this skill simply because the user requests cinematic visuals.

Only apply color processing when it improves realism, continuity, or the intended emotional tone.

---

# Application Philosophy

Treat color processing as the technical and artistic foundation of the final image.

Its influence should reinforce:

- color accuracy
- tonal balance
- realistic lighting
- dynamic range
- visual consistency
- emotional atmosphere

Every adjustment should strengthen the image without making the processing itself obvious.

Favor natural, balanced color over exaggerated grading unless a stylized aesthetic is intentionally requested.

---

# Visual Translation

Rather than outputting only:

```
Color Correction
```

or

```
HDR
```

translate the chosen treatment into visible image characteristics.

Describe elements such as:

- balanced color reproduction
- natural skin tones
- controlled highlight detail
- preserved shadow information
- expanded tonal range
- refined color temperature
- cohesive cinematic color

The treatment should be expressed through photographic qualities rather than technical terminology alone.

---

# Style Boundaries

Avoid treating color processing as creative color grading.

Every adjustment should remain consistent with:

- cinematography
- lighting
- camera system
- director style
- cinematic movement
- image finishing

Avoid exaggerated saturation, unnatural contrast, or unrealistic color shifts unless explicitly required by the narrative or artistic direction.

Technical consistency should remain the default.

---

# Default Behavior

If no color processing is requested:

- preserve natural color balance
- maintain realistic white balance
- protect highlight and shadow detail
- preserve accurate skin tones
- apply clean cinematic color reproduction

The image should appear professionally color-managed without drawing attention to the processing.

---

# Final Principle

Color processing establishes the visual foundation of the image.

Its purpose is to improve clarity, consistency, and tonal balance while preserving the emotional intent of the cinematography.

The best color processing feels effortless—it allows the audience to focus on the story rather than the image manipulation.
